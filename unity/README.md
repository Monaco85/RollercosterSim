# Achterbahn – Unity-Fassung

Unity-6-Projekt (6000.0.85f2, URP) der Achterbahn für den 2DOF-Sitz. Physik, Motion-Werte und Telemetrie-Frame sind 1:1 aus `web-quelltext` übernommen.

- Öffnen: Ordner `unity` im Unity Hub hinzufügen.
- Bauen: Menü **Achterbahn > Programm bauen** → `Build/Achterbahn.exe`.
- Grafik einrichten (nach frischem Klonen falls nötig): **Achterbahn > Assets einrichten**.
- Sitz: Die Brücke (`bridge`) muss laufen. Im Editor ist der Sitz gesperrt, bis man ihn über **Achterbahn > Sitz im Editor verbinden** freigibt.
- Bedienung: Leertaste/Enter/Lenkradtaste Start · C Kamera · 1–5 Bahn · Esc Bahnwahl, 2× Esc Beenden · F11 Fenster/Vollbild.

Texturen, Modelle und HDRI stammen von [Poly Haven](https://polyhaven.com) (CC0), siehe `Assets/PolyHaven/QUELLE_CC0.txt`.
